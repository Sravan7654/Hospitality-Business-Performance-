# Hospitality Business Performance & Customer Insights

## Project Overview
This project focuses on analysing hotel booking data to understand hospitality business performance, customer booking behaviour and reservation cancellation patterns.

## Project Objectives
- Analyse hotel booking trends and customer behaviour.
- Identify factors influencing booking cancellations.
- Evaluate hotel booking performance.
- Develop machine learning models to predict cancellations.
- Compare models and identify the best-performing algorithms.

## Dataset
**Hotel Booking Demand Dataset**

Source: [Kaggle – Hotel Booking Demand](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand)

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Kaggle Notebook

## Machine Learning Algorithms
1. Logistic Regression
2. Decision Tree
3. K-Nearest Neighbors (KNN)
4. Random Forest
5. Gradient Boosting

## Model Performance
The models were evaluated using Accuracy, Precision, Recall, F1 Score and ROC-AUC.

| Algorithm | F1 Score |
|---|---:|
| Random Forest | 82.67% |
| Gradient Boosting | 82.06% |

Random Forest achieved the highest F1 Score among the five models.

## Key Findings
Deposit type, country, market segment and lead time were among the most influential features in the model's predictions.
